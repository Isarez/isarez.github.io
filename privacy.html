3ข้อมูลที่เกมใช้

ทุกคน — รวมถึงผู้เล่นแบบผู้เยี่ยมชม

ข้อมูลใช้ทำอะไรอยู่ที่ไหน · ใครได้รับ
เซฟเกม — ปลา ยีน ความคืบหน้า เงินในเกม การตั้งค่า ภาษา ฉบับข้อตกลงที่ยอมรับและเวลาที่ยอมรับ รหัสคำสั่งซื้อของ Google Play (กันการให้ของซ้ำ) และรหัสเครื่องแบบสุ่มที่เกมสร้างเอง (ไม่ใช่รหัสเครื่องจริง)ให้เกมเล่นต่อได้ในเครื่องของคุณเท่านั้น — ผู้เยี่ยมชมไม่มีอะไรส่งถึงเรา
ข้อมูลที่ SDK โฆษณาของ Google (AdMob) เก็บเอง — รหัสโฆษณาของ Android และรหัสชุดแอป · ที่อยู่ IP (ใช้ประมาณตำแหน่งระดับเมือง/ประเทศ) · การโต้ตอบกับแอปและโฆษณา (เช่น การเปิดแอป การแตะ การดูวิดีโอ) · ข้อมูลประสิทธิภาพและการวินิจฉัยแสดงและวัดผลโฆษณาแบบให้รางวัล · วิเคราะห์ · ป้องกันการฉ้อโกงส่งถึง Google โดยตรง — SDK เริ่มทำงานหลังคุณกดยอมรับข้อตกลง และโหลดโฆษณารอไว้ล่วงหน้า จึงอาจเก็บข้อมูลเหล่านี้แม้ยังไม่ได้กดดู · โฆษณาจะแสดงเฉพาะตอนคุณกดดูเพื่อรับรางวัลเท่านั้น
การซื้อในแอป — รหัสสินค้า รหัสคำสั่งซื้อ สถานะการซื้อมอบของในเกมและกันการให้ซ้ำGoogle Play เป็นผู้รับชำระเงิน — เราไม่เห็นชื่อ อีเมล หรือข้อมูลบัตร

เมื่อคุณเปิดระบบออนไลน์ (ทางเลือก · อายุ 13 ปีขึ้นไป)

เกมแสดงรายการข้อมูลที่จะส่งและให้คุณกดยืนยันก่อน ไม่มีอะไรถูกส่งจนกว่าจะกดเข้าสู่ระบบ · ระบบออนไลน์ยังไม่เปิดในทุกรุ่นของเกม

ข้อมูลใช้ทำอะไรเก็บที่ · ใครเห็น
รหัสผู้เล่นของ Unity และรหัสผู้เล่นจาก Google Play Games ที่ใช้เข้าสู่ระบบระบุบัญชีของคุณUnity Authentication · รหัสของ Unity ถูกส่งไปพร้อมแถวอันดับเพื่อให้ผู้เล่นอื่นซ่อนหรือรายงานได้ (ไม่แสดงบนจอ)
ที่อยู่ IPบริการของ Unity รับทุกครั้งที่เกมเชื่อมต่อ เพื่อให้บริการและความปลอดภัยUnity — เราไม่ได้เก็บแยก
สำเนาเซฟเกม (ข้อมูลเดียวกับเซฟในเครื่อง ยกเว้นชื่อที่แสดงและช่วงอายุ ซึ่งไม่ถูกส่งขึ้นคลาวด์)เล่นต่อบนเครื่องใหม่ · กู้เซฟเมื่อลงแอปใหม่Unity Cloud Save — ส่วนตัว เห็นได้เฉพาะบัญชีของคุณ
ชื่อที่แสดง (ชื่อเล่นจากโปรไฟล์ Google Play Games) และตัวเลือกซ่อนชื่อแสดงในอันดับเหวฤดูกาลระบบชื่อผู้เล่นของ Unity Authentication (Player Names) ซึ่งอันดับใน Unity Leaderboards อ่านไปแสดง — ผู้เล่นอื่นเห็น · ตัวเลือกซ่อนชื่อเก็บใน Unity Cloud Save (สาธารณะ เฉพาะว่าซ่อนหรือไม่ ไม่มีชื่อ) · ซ่อนแล้วชื่อในระบบถูกแทนด้วยชื่อกลาง และอันดับแสดงเป็น "ผู้เล่นใต้เหว #ตัวเลขสี่หลัก"
ช่วงอายุ (ต่ำกว่า 13 / 13 ขึ้นไป) — ไม่เก็บวันเกิดตัดสินว่าเปิดระบบออนไลน์ได้ไหม · ตั้งโฆษณาแบบสำหรับเด็ก (หัวข้อ 11)ในเซฟในเครื่องเท่านั้น — ไม่ส่งขึ้นคลาวด์
ผลเหวฤดูกาล — คะแนนดีสุด ความลึก ระดับ ธาตุ รหัสปลาในทีมที่ทำคะแนนดีสุด จำนวนครั้งที่ส่งต่อวัน กลุ่มค่าพลัง ผลการตรวจจัดอันดับ · คิดโบนัสความสดของทีม · จำกัดการส่ง · ตรวจการโกงUnity Cloud Save (ส่วนที่เครื่องแก้ไม่ได้) และ Unity Leaderboards — ผู้เล่นอื่นเห็นอันดับ คะแนน ความลึก ธาตุ และชื่อ (ถ้าไม่ซ่อน)
บันทึกการกดของแต่ละรอบ (เมล็ดสุ่ม ลำดับการกด)เซิร์ฟเวอร์คิดผลซ้ำทุกชั้นเพื่อยืนยันคะแนนUnity Cloud Code ประมวลผลแล้วไม่เก็บ · ถ้าส่งไม่สำเร็จ เกมเก็บไว้ในเครื่องเพื่อส่งใหม่
บันทึกตรวจการโกง (รอบ ช่อง เหตุที่คะแนนไม่ผ่าน เวลา)ป้องกันการโกงและดูแลความยุติธรรมของอันดับUnity Cloud Save — เฉพาะเรา
รายงานผู้เล่น — เมื่อคุณรายงานคะแนน: รหัสของผู้ถูกรายงาน เหตุผล เวลา และรหัสของคุณในรูปแฮชที่ย้อนกลับไม่ได้ตรวจคะแนนผิดปกติ · กันการรายงานซ้ำUnity Cloud Save — เฉพาะเรา
รายงานชื่อ ผ่าน Google Forms — แบบฟอร์มเติมรหัส ชื่อที่เห็น และรอบของคนที่ถูกรายงานไว้ให้ คุณเลือกเหตุผลแล้วกดส่งเอง (แบบฟอร์มไม่เก็บอีเมลและไม่ต้องลงชื่อเข้าใช้)ตรวจชื่อที่ไม่เหมาะสมGoogle Forms ของเรา — เฉพาะเรา
บันทึกการทำงานของเซิร์ฟเวอร์ (เวลา รหัสผู้เล่นแบบย่อ ผลการทำงาน)แก้ปัญหาและรักษาความปลอดภัยUnity — เฉพาะเรา

4ผู้ที่ได้รับข้อมูล

  • Google — โฆษณา (AdMob) · การซื้อในแอป (Google Play Billing) · การเข้าสู่ระบบ (Google Play Games) · แบบฟอร์มรายงานชื่อ (Google Forms) — นโยบายความเป็นส่วนตัวของ Google · วิธีที่ Google ใช้ข้อมูลจากแอปที่ใช้บริการของ Google
  • Unity Technologies — บัญชี เซฟบนคลาวด์ อันดับ และการคิดผลบนเซิร์ฟเวอร์ (Unity Gaming Services) ในฐานะผู้ประมวลผลข้อมูลแทนเรา — นโยบายของ Unity
  • GitHub — ผู้ให้บริการเว็บไซต์
  • ผู้เล่นคนอื่น — เห็นชื่อที่แสดง (ถ้าไม่ซ่อน) อันดับ คะแนน ความลึก และธาตุของคุณในเหวฤดูกาล
  • หน่วยงานรัฐ — เมื่อกฎหมายบังคับเท่านั้น

เราไม่ขาย ไม่ให้เช่า และไม่แลกเปลี่ยนข้อมูลส่วนบุคคล และไม่ได้ใช้ข้อมูลทำโปรไฟล์เพื่อการตลาดเอง

5วัตถุประสงค์และฐานทางกฎหมาย

วัตถุประสงค์ฐานทางกฎหมาย (PDPA · GDPR)
ให้บริการระบบออนไลน์ที่คุณเลือกเปิด — บัญชี เซฟบนคลาวด์ อันดับ เหวฤดูกาลจำเป็นเพื่อปฏิบัติตามสัญญา (ข้อตกลงการใช้งาน) — PDPA ม.24(3) · GDPR ข้อ 6(1)(b)
มอบของที่ซื้อและกันการให้ของซ้ำจำเป็นเพื่อปฏิบัติตามสัญญา
ตรวจคะแนน ป้องกันการโกง จำกัดการส่ง และรักษาความปลอดภัยของระบบประโยชน์โดยชอบด้วยกฎหมาย (เกมแข่งที่ยุติธรรมและระบบที่ปลอดภัย) — PDPA ม.24(5) · GDPR ข้อ 6(1)(f)
แสดงโฆษณาแบบให้รางวัลและวัดผล (ไม่ปรับตามบุคคล)ประโยชน์โดยชอบด้วยกฎหมาย (ให้เกมเล่นได้ฟรี)
โฆษณาที่ปรับตามบุคคล และการใช้ที่เก็บข้อมูลในเครื่องเพื่อโฆษณา ในพื้นที่ที่กฎหมายกำหนดให้ต้องขอความยินยอมความยินยอม ผ่านหน้าขอความยินยอมของ Google — ถอนได้ทุกเมื่อในหน้าตั้งค่าของเกม
ตอบคำขอใช้สิทธิและเรื่องร้องเรียน · เก็บหลักฐานว่าลบบัญชีแล้วหน้าที่ตามกฎหมาย และประโยชน์โดยชอบด้วยกฎหมาย

การให้ข้อมูลเพื่อเปิดระบบออนไลน์เป็นทางเลือก ไม่ใช่หน้าที่ตามกฎหมาย — ถ้าไม่ให้ คุณยังเล่นคนเดียวได้ครบทุกโหมด

  • ความแม่นยำที่ผิดปกติ (เช่น กดทันจังหวะเกือบทุกครั้ง) ถูกจดไว้ให้คนตรวจ — ระบบไม่แบนอัตโนมัติ
  • กลุ่มค่าพลัง ของอันดับคิดอัตโนมัติจากปลาที่แรงที่สุดในเซฟของคุณ
  • ถ้าคิดว่าผลไม่ถูกต้อง ขอให้คนตรวจทานได้ที่ nech.studios@gmail.com

7การส่งข้อมูลไปต่างประเทศ

Google, Unity และ GitHub อาจเก็บและประมวลผลข้อมูลบนเซิร์ฟเวอร์นอกประเทศไทย เช่น สหรัฐอเมริกาและประเทศในสหภาพยุโรป · ผู้ให้บริการเหล่านี้คุ้มครองข้อมูลตามสัญญาประมวลผลข้อมูลของตน รวมถึงข้อสัญญามาตรฐาน (Standard Contractual Clauses) หรือกรอบการคุ้มครองที่กฎหมายรับรอง ตามที่ PDPA มาตรา 28–29 และ GDPR หมวด 5 กำหนด

6Automated decision-making

  • Season Abyss score checks — the server replays your input log with the same rules as the game; if the result does not follow the rules, that score is automatically kept off the leaderboard.

  • Your leaderboard power group is calculated automatically from the strongest fish in your save.
